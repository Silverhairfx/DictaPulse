## DictaPulse v0.2.0

A feature and polish release for Linux (KDE Plasma 6, Wayland).

### What's changed
- **New: pick your cleanup model from a dropdown.** When cleanup is set to a local LLM, the Cleanup page now lists the models installed in LM Studio or Ollama and lets you pick one. A "Download a model" option opens step by step instructions (including the headless `lms get` / `ollama pull` commands), and the chosen model loads automatically on use, so you never need the LM Studio or Ollama GUI.
- **New: a distinct start-recording sound.** The overlay now plays a separate rising cue when recording starts, in addition to the existing stop cue.
- **Fix: overlay sounds no longer get dropped.** An idle audio device could swallow the first cue; both the start and stop cues now play reliably.
- **Fix: text sits centered in input fields.** Text was seated slightly high in every text box; it now aligns to the optical center.
- **Change: recording length is no longer capped by default.** A dictation now records until you stop it. Advanced settings has a clear control to set a safety cap (No limit / 1 / 5 / 15 / 30 minutes) if you want one.
- **Build: Vulkan GPU acceleration auto-enables on Linux** when the Vulkan loader is present, so a source build no longer falls back to CPU by accident. It still falls back to CPU automatically when no GPU is available.
- **Docs:** added a public `ROADMAP.md`.

### Install
- **Download and run (AppImage, Vulkan):** grab `DictaPulse-0.2.0-x86_64.AppImage` below, then:
  ```bash
  chmod +x DictaPulse-0.2.0-x86_64.AppImage
  ./DictaPulse-0.2.0-x86_64.AppImage
  ```
  Needs KDE Plasma 6 (Wayland), a running `ydotoold`, and host ffmpeg (present on most desktops). GPU use needs a Vulkan driver; otherwise it falls back to CPU.
- **Arch / CachyOS:** install `dictapulse` (source) or `dictapulse-bin` (prebuilt) from the AUR, or build from source:
  ```bash
  git clone https://github.com/Silverhairfx/DictaPulse.git
  cd DictaPulse && ./scripts/install.sh
  ```
- See the [README](https://github.com/Silverhairfx/DictaPulse#-quick-install-arch--cachyos) for full requirements, first-run setup, and the model picker.
